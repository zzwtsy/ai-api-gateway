# 事故复盘

Postmortem 用于记录已经逃逸到真实入口、发布产物或用户环境的缺陷，以及几乎造成同等影响的近失误。普通 Bug 不需要复盘。

一份有效复盘必须回答：

1. 用户或系统实际受到了什么影响；
2. 哪个运行时关系被破坏；
3. 为什么原有 Typecheck、Unit、Fixture 或 CI 没有捕获；
4. 哪个更接近真实入口的证据现在能够捕获；
5. 哪条局部规则、运行时不变量或 Gate 永久防止同类缺陷；
6. 是否通过重新引入缺陷证明新 Guard 会失败。

复盘不是责备记录，也不保存推理流水账。只保留经过证据确认的时间线、根因、缺失证据和永久措施。
